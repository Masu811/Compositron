# Compositron C++ Kernel

## Requirements

The Compositron C++ Kernel uses the C++23 standard and will not work with any lower version.

## Dependencies

The Compositron C++ Kernel uses third party libraries. Those that come with the same license as Compositron (the MIT-license) are shipped with this repository. Those with different licenses need to be installed by you. These are

- Eigen linear algebra template library (tested with v5.0.1, but lower versions might still work)
- Ceres Solver for non-linear least squares fitting (v2.3.0)
